World compatibility

VuencEdit reads and writes every Eden world format the game itself has ever shipped, and detects which one it's looking at automatically.

Legacy64z
The original format — 64 height levels.
NewDawn256z
The New Dawn update — 256 height levels.
NewFormat256z
A 2026 update — 256 levels, new blocks, signs.
