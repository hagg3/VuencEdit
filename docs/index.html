World compatibility

VuencEdit opens all three world formats the game has used and detects which one a file is. Saving keeps the format it was loaded in.

Legacy64z
The original format. 64 height levels.
NewDawn256z
The New Dawn update. 256 height levels.
NewFormat256z
A 2026 update. 256 levels, new blocks, signs.
