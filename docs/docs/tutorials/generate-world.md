## 1. Open New World

Press <kbd>⌘N</kbd> (<kbd>Ctrl+N</kbd>), or click **New** on the splash screen.

{% include placeholder.html caption="The New World dialog on the Natural generator" file="tut-gen-01-dialog.webp" shot="New World dialog, Natural selected in the left list, default settings, preview visible" %}

## 2. Pick a generator

The list on the left has four:

- **Flat**: a flat stone and dirt slab. Set the stone and dirt depth.
- **Natural**: biomes, rivers, caves and structures (experimental).
- **Classic**: the original Eden terrain.
- **TG2**: Eden 2.0 terrain (experimental).

## 3. Choose the format and size

Under Height format, pick **Legacy 64z** or **New Dawn 256z**. Current Eden opens 64z worlds and converts them to 256z. The dialog's footer shows the resulting size. 256z is the usual choice. Some options, such as Extreme mountains, need 256z.

## 4. Set the terrain

Set water, biome and features for Natural, or the layer depths for Flat. The dice button next to the seed picks a random one. The same seed and settings give the same world, so write the seed down if you like the result.

## 5. Name it and create

Type a name (required), then click **Create World…** and pick where to save it. A progress percentage shows in the button. **Cancel generation** stops it and discards the partial world.

{% include placeholder.html caption="Generation in progress, the button showing a percentage" file="tut-gen-02-progress.webp" shot="New World dialog mid-generation, button reading 'Creating… 40%'" ratio="4/3" %}

When it finishes, the world opens on the map. Take a look in 3D (<kbd>⌥3</kbd>) to see what you got.
