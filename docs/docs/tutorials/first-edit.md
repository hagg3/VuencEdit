You'll need a `.eden` file. If you don't have one, make a flat world with New (see [Generate a world]({{ '/docs/tutorials/generate-world/' | relative_url }})).

## 1. Open a world

On the splash screen, click **Open** and pick your file. The map loads as a top-down, colour-coded view.

{% include placeholder.html caption="The splash screen with New, Open, Download and Recent Worlds" file="tut-first-01-splash.webp" shot="1280x800 window, splash screen, a few recent worlds listed" %}

## 2. Pick a block

Click the **Block** button on the Draw tab. Type in its search box, for example `grass`, and click a block. Or press a hotbar key: <kbd>1</kbd> to <kbd>5</kbd> for pinned blocks, <kbd>6</kbd> to <kbd>0</kbd> for recent ones.

{% include placeholder.html caption="The block picker open with the search box filled in" file="tut-first-02-picker.webp" shot="Draw tab, Block picker open, 'grass' typed in the search box" ratio="4/3" %}

## 3. Paint

Press <kbd>B</kbd> for the Brush and look at the options bar under the ribbon: set the size to 3. Drag across the map. Then try Rectangle (<kbd>R</kbd>) and drag a box.

{% include placeholder.html caption="A brush stroke and a rectangle painted on the map, with the options bar visible" file="tut-first-03-paint.webp" shot="Map zoomed to about 8 px per block, Brush armed at size 3, one stroke and one rectangle drawn; options bar in frame" %}

## 4. Undo

Press <kbd>⌘Z</kbd> (<kbd>Ctrl+Z</kbd> on Windows and Linux). A whole stroke undoes in one step. The History tab in the sidebar lists every step.

## 5. Save

Press <kbd>⌘S</kbd> (<kbd>Ctrl+S</kbd>). The first save over a file keeps a backup next to it. Use **Save As…** (<kbd>⇧⌘S</kbd>) to write a copy elsewhere.

{% include placeholder.html caption="The History tab listing the steps from this session" file="tut-first-04-history.webp" shot="Sidebar History tab open, 4 to 5 entries, newest at the top" ratio="4/3" %}
